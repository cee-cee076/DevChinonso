# Chinonso Caleb Ozurumba — Portfolio Website

A modern, professional, fully responsive Front-End Developer portfolio with 3D-inspired design, glassmorphism cards, floating animations, and a working mobile hamburger menu.

## Features

- Dark premium theme with soft cyan/purple accents
- 3D profile card with floating skill badges
- Glassmorphism skill & project cards with hover depth
- Working hamburger menu (mobile)
- Smooth scroll + active nav highlighting
- Scroll fade-up animations
- Download CV button (ready for your link)
- Fully responsive (mobile-first)
- Clean, accessible HTML structure

## How to Use

1. Open `index.html` in any modern browser
2. Replace the **Download CV** button link:
   - Find: `<a href="#" class="btn btn-outline" id="download-cv" ...>`
   - Change `href="#"` to your actual CV link (Google Drive, Dropbox, or direct PDF)
3. Add your photos:
   - Hero profile: replace the `.photo-placeholder` inside `.profile-image`
   - About section: replace the `.photo-placeholder` inside `.about-photo-card`
4. Update project links and add real project screenshots when ready
